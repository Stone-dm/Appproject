# 机巧江湖离线运行说明

适用于同目录包含 `启动本地演示.exe` 和 `机巧江湖_本地演示.apk` 的运行文件夹。

1. 将文件完整解压到 Windows x64 电脑的可写目录，不在压缩包内运行。
2. 双击 `启动本地演示.exe`，等待窗口显示服务已启动，保持窗口开启。默认端口是 8011。
3. 将 `机巧江湖_本地演示.apk` 安装到 Android 7.0 或以上手机/模拟器；首次侧载按系统提示允许安装。
4. 手机与电脑连接同一局域网，APP 连接页填写 EXE 显示的电脑地址；Android Studio 模拟器通常使用 `http://10.0.2.2:8011`。Windows 防火墙弹窗仅允许所需的可信专用网络。
5. 登录账号 `13900000001` 或 `13900000002`，密码均为 `JqjhReview2026!`。这是本地虚拟演示账号，不需要短信。
6. 体验学习内容、创作和保存记录。关闭服务前先完成当前操作；重启后继续使用原数据目录。

此运行方式不需要 Python、Docker、Android Studio 或在线模型密钥。EXE 首次运行会在附近创建 `本地数据/`，以后继续使用这些数据。换目录或换电脑时连同数据目录一起复制。不要删除数据目录后期待旧作品仍然存在。

离线教练、图片、评审和部分媒体处理是规则或程序模拟，不代表在线 AI 效果和正式生产审核。教师/班级/审核等流程可能需要额外配置数据。现有 APK 使用开发签名；设备如已有同包名、不同签名版本，安装可能提示冲突，先确认原应用数据如何保留再处理。

端口被占用时可在 EXE 窗口调整，并同步修改 APP 地址。手机连不上时依次核对服务状态、同一局域网、电脑地址、端口及专用网络防火墙权限。不要通过关闭所有防护或停止其他项目来掩盖配置问题。

继续开发请回到完整交接包根目录阅读 `00-先读我.md`、`项目交接文档.md` 和 `handover/project.json`。
