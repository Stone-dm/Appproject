1. 阅读 [完整项目交接文档](项目交接文档.md)，也可双击 [浏览器阅读版](项目交接文档.html)。AI 同时阅读 [项目地图](../../handover/project.json) 和 [协作约定](../../CONTRIBUTING.md)。
2. 安装 Windows x64 的 Python 3.13；修改 Android 还需 Android Studio、JDK/JBR 21、Android SDK 35。
3. 在解压根目录运行：

   ```powershell
   py -3.13 handover/manage.py doctor

   py -3.13 handover/manage.py test
   ```

```powershell
Get-FileHash .\JiqiaoJianghu-Handover-20261011.zip -Algorithm SHA256
```
